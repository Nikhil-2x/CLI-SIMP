● The best option is a self-contained .tools folder inside the project, using a
  Python virtualenv plus two downloaded binaries. It needs no pipx and no
  ensurepath, and it never touches system folders. Deleting it afterwards is a
  single rm -rf.

  I'm assuming .tools/ isn't gitignored yet. Add .tools/ to .gitignore first so
  it can't get committed by accident.

  Install

  Run these from the repo root:

  mkdir -p .tools/bin

  # Semgrep + Bandit in a local virtualenv
  python3 -m venv .tools/venv
  .tools/venv/bin/pip install semgrep bandit
  ln -s "$PWD/.tools/venv/bin/semgrep" .tools/bin/semgrep
  ln -s "$PWD/.tools/venv/bin/bandit"  .tools/bin/bandit

  For Gitleaks and OSV-Scanner, download the Linux amd64 binaries from their
  GitHub releases pages:
  - Gitleaks: https://github.com/gitleaks/gitleaks/releases
  - OSV-Scanner: https://github.com/google/osv-scanner/releases

  Put them in .tools/bin/ as gitleaks and osv-scanner. Extract the Gitleaks
  tarball first, then run chmod +x .tools/bin/*.

  The python3 -m venv step may fail with an "ensurepip is not available" error
  on Pop!_OS. If so, sudo apt install python3-venv fixes it. That's the only
  system-level package this route can need, and sudo apt remove python3-venv
  undoes it.

  Use

  Add the tools to PATH for the current terminal only:

  export PATH="$PWD/.tools/bin:$PATH"

  Then check them:

  semgrep --version && bandit --version && gitleaks version && osv-scanner
  --version
  du -sh .tools      # actual space used

  Closing the terminal drops the PATH change, so nothing is permanent.

  Delete after the project

  rm -rf .tools ~/.semgrep ~/.cache/pip
  # optional, only if you installed python3-venv:
  sudo apt remove python3-venv

  ~/.semgrep holds Semgrep's rule cache. That leaves no leftovers outside the
  project and those two cache folders.

  Why not the others?

  - pipx: it installs tools into ~/.local and edits your shell config, and it's
    more steps to undo.
  - Docker: it also cleans up easily. But it would need wrapper scripts, scans
    are slower, and the images are larger.

  If you'd rather skip Semgrep (the biggest download), you can leave it out and
  install it later. The other three tools are small, and you can still test
  Bandit, Gitleaks, OSV and the WM rules without it.
